**前言**

长期以来，黑乐谱社区的人数呈现缓慢增加的趋势。而随着黑乐谱的逐渐发展，以及相关技术体系的逐渐成熟，将此类技术汇总成为教程，指引新加入的创作者及爱好者们了解黑乐谱制作的相关要领，是尤为重要的。一直以来，国内黑乐谱社区的教程都没有形成较为完整的体系，导致了黑乐谱入门门槛高，黑乐谱创作严重依赖自学或先前音乐学习经验的问题。多数情况下，这容易让新人摸不着头脑，不知道从哪里下手，提高自己的技术水平。更糟糕的是，正因为教程体系的缺失以及基础理论的不完整，让大部分人因为一些难以解决的基础性问题，被迫放弃，搁置黑乐谱的创作（这正是我曾经的亲身经历）。

这正是创作本篇教程的初衷，希望广大黑乐谱创作者能够由浅入深，系统而完整地了解黑乐谱的创作过程。构建完善的基础教程体系，是发展黑乐谱的必经之路，随着CBMS后续宏观政策的调整，社区内人员的变动，以及接下来将要承担吸纳新人的重任，及时制作这样一本通用教程的必要性也凸显出来，这份工作也相应地被提上日程。

千里之行，始于足下。2013年以来，自中国黑乐谱社区建立，像这样综合性的“黑乐谱说明书”是前所未有的。此刻，我们已然走过十一年的光景，那么从今天开始，这份百科全书将汇聚所有创作者的心血与结晶，开始它光辉而灿烂的征程。也希望热爱黑乐谱的你，能够耐心地将它看完，一起领略独属于黑乐谱的，神奇而又略显疯狂的美学。

**——IMT11D，CBMS第二任会长，2024.5.17**

**使用说明**

**本教程完全开源，欢迎各位创作者进行编辑，不断完善教程体系的建设。**

投稿方式：教程正文托管于 GitHub 仓库（<https://github.com/IMT11D/black-midi-tutorial>）。熟悉 Git 的创作者可直接提交 Pull Request；不便使用 GitHub 的，可在仓库中通过“投稿”Issue 模板投稿，或将 txt、小块 Word 文档上传至社区 NAS 投稿链接（<http://cbmsmedia.online/sharing/C2EPVLvSJ>），由维护组统一录入。投稿要求与说明模板详见仓库根目录的《编写指南》（CONTRIBUTING.md）。

格式要求：正文以 Markdown 维护，标题采用三级编号结构（如 # 1 / ## 1.1 / ### 1.1.1），新增内容请沿用所属章节的编号，不要打乱既有编号。空行、图片、公式、侧边栏等格式规范详见《编写指南》；最终发布前的排版样式由维护组统一处理。

**本教程除技术标准、代码、注释的理论内容，其余的正文部分严禁使用任何AI工具进行直接编辑（但一定程度上允许使用AI工具精练语言；使用AI/Agent协助格式整理不受此限）。**

版本号的说明：

不再区分 Alpha / Beta 阶段。版本号格式为「年-月-日-当日序号」（如 26-10-04-01），由 CI 在合并/推送时自动更新，无需手动维护。Release 版本在版本号后加 -REL 后缀（如 26-10-04-01-REL），表示可对外分发的正式版本。

文件名称示例：黑乐谱综合教程-26-10-04-01；Release 版本：黑乐谱综合教程-26-10-04-01-REL。

Release 版本最终以PDF格式发布，理论上为可打印格式，且内容将不受到打开设备与软件的影响。

标注必读内容为黑乐谱入门的基础内容（编写时优先完成），而对于选读内容，推荐在有音乐学习经历基础上进行阅读（对于群内有较高讨论热度的公认高阶创作方法按需添加）。***（20260124更新：确认本教程前五章为必读内容）***
