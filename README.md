## 关于本教程

《黑乐谱综合教程》是一份面向黑乐谱创作者与爱好者的系统性中文教程，旨在改变国内黑乐谱社区教程零散、入门门槛高的现状，让创作者能够由浅入深、系统而完整地了解黑乐谱的创作过程。

教程内容覆盖**制作环境搭建、MIDI 创作、音符画、音频渲染、视频制作、音色库制作、混音母带、乐理与编曲**等完整流程。其中前五章为入门必读内容，标注“选读”的章节推荐在具备一定音乐基础后再阅读。目前教程内容仍在持续补充与完善中。

> 希望热爱黑乐谱的你，能够耐心地将它看完，一起领略独属于黑乐谱的，神奇而又略显疯狂的美学。
>
> —— IMT11D，CBMS 第二任会长，2024.5.17

## 参与编写

**本教程完全开源，欢迎各位创作者参与编辑，不断完善教程体系的建设。**

- **提交方式**
  - 主要方式（GitHub）：有写权限的协作者可直接推送到 `dev` 分支，其他贡献者向 `dev` 发起 Pull Request；不会 Git 命令的可用**网页编辑器**在线修改（自动 Fork），或通过“投稿”Issue 模板投稿（直接拖拽上传 txt / Word / 图片等附件）；
  - 备用方式：无法访问 GitHub 时，可通过社区 NAS 投稿链接上传 txt 或小块 Word 文档（链接见《编写指南》）；
  - 问题反馈：笔误、过时内容、失效链接等欢迎直接提交 Issue。
- **内容红线**：除技术标准、代码、注释等理论内容外，正文部分严禁使用 AI 工具直接编辑（允许使用 AI 精练语言）；**使用 AI / Agent 协助格式整理是允许的**（如编号检查、空行规范、锚点与路径检查），提交前请人工复核。
- **版本号说明**：版本号格式为「年-月-日-当日序号」（如 `26-10-04-01`），由 CI 在合并/推送时自动更新，无需手动维护；不再区分 Alpha / Beta 阶段；**Release 版本**在版本号后加 `-REL` 后缀（如 `26-10-04-01-REL`），最终将以 PDF 格式发布。

完整的提交要求与格式规范（标题编号、空行、图片、公式、侧边栏生成等）请见 **[《编写指南》](CONTRIBUTING.md)**。

维护组：发布与合并流程见「[发布流程（维护组）](CONTRIBUTING.md#七发布流程维护组)」。
